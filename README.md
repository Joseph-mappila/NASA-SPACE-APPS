# Aster Outpost

Working repository for the 2026 NASA Space Apps Challenge: Junior Astronaut Mission Trainer.

## Current direction

A mobile-first illustrated Mars survival story for ages 7–12. Players make mission trade-offs, perform short tactile procedures, and see persistent consequences across power, life support, food, and rescue readiness.

# 🧑‍🚀 Character Avatars Placeholder Folder

Add your character portrait images here! They will automatically display inside the in-game dialogue box beside character speech.

### Recommended Files:
- `commander.png` — **Commander Chen** (Expedition Commander)
- `hal.png` — **HAL-Jr** (AI Mission Assistant)
- `medic.png` — **Dr. Patel** (Chief Medical Officer)
- `cadet.png` — **Cadet** (Player character)
- `system.png` — **Station System** (Automated station alerts)

### Specifications:
- **Format:** PNG or WebP (transparent or styled background)
- **Dimensions:** 256×256 px or 512×512 px (1:1 square aspect ratio)
- Files in this directory are served directly by Vite at `/avatars/<filename>` and are linked in `src/components/DialogueBox/DialogueBox.jsx`.
